# Video playback from image thumbnails

Image Block and Carousel, Filmstrip, Grid, Justified, Modular and Masonry support the premium `video_lightbox` click action. Existing image blocks, serialized names, and image lightbox behavior are retained.

The image remains the thumbnail. Each Image Block stores its own `videoLightboxUrl`; galleries provide click/hover appearance through existing context. URLs can be entered in Image Click Settings, selected through the video media picker, or edited through the image toolbar. The per-image source controls remain available when gallery click overrides are disabled.

Controls follow this order: Link Target (Icon/Thumbnail), Display Link Target Icon (On Hover/Always, when targeting Icon), Lightbox Appearance, Lightbox Content, and (for galleries only) Show Image Counter. Zoom is omitted for video. Play icons use existing link icon colors in Click Styles. `video_play` overlay content is offered only for the video click action and follows the existing hover overlay style. Overlay and independent click icons can be displayed together.

The image lightbox accepts mixed image/video slides. Provider URLs are generated by `videoProviders.js`; self-hosted URLs use a native video element. Closing, changing slides, and disposing a gallery detach provider iframes and stop/remove native video sources. Video slides force visible lightbox controls and omit image zoom and image watermarks. Missing or unsafe video URLs do not create a video trigger.

Filmstrip uses its own hidden lightbox proxies; these carry the individual video source and per-image appearance/zoom/counter overrides. Carousel clones retain their existing inert status and are excluded from lightbox navigation.

Global Block Defaults expose shared behavior and appearance, but do not expose a shared video URL.

- `node scripts/tests/image-video-controls.cjs` checks registered attributes and editor controls.
- `php scripts/tests/block-defaults.php` and `node scripts/tests/image-block-defaults.cjs` check defaults and conditional controls.
- `php scripts/tests/render-image-video-fixtures.php` renders existing local attachments without saving content.
- Generate a silent test clip with `ffmpeg -f lavfi -i color=c=black:s=160x90:r=12 -t 3 -c:v libx264 -pix_fmt yuv420p -movflags +faststart -an -y /private/tmp/fbks-lightbox-test.mp4`.
- `node scripts/tests/image-video-lightbox.cjs` uses installed Chrome to check all six galleries, mixed media navigation, real native playback, cleanup, controls, and missing/unsafe URLs. Provider network responses are mocked. Set `FBKS_TEST_VIDEO` to use another local MP4, and `FBKS_TEST_SCREENSHOT` to capture the opened lightbox.
- Existing Image and Slider navigation tests cover image-only behavior and router cleanup.
